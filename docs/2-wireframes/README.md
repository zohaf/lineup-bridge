# Wireframes

2026-11-05 · approved · Figma: LineupBridge file (linked below)

The Figma file holds the visual design. Its Foundations, Components, Layouts and Pages mirror the
code (code leads, see [rules.md §2](../4-design-system/rules.md#2-sources-and-sync)); Journeys and
Wireframes are where user flows are worked out.

| Figma page | Contents |
| --- | --- |
| Foundations | Variables from `src/styles/lineupTokens.css` |
| Components | Library components, linked to code |
| Layouts | Centered and Split layouts |
| Pages | Built app screens, phone and desktop |
| Journeys | Screens in order per journey |
| Wireframes | Greyscale versions of the pages |

Figma file: [LineupBridge](https://www.figma.com/design/uUt1bfNw7imHngWi1QFXGJ)
