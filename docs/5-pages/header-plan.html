LineupBridge header: what users see today, and the plan to move every page to the new bar

The new 60px bar is live for logged-out visitors and for the offer builder and checkout. Every logged-in page still shows the old Sharetribe topbar, its avatar dropdown and its full-screen phone menu. This page maps every scenario, proposes the new dropdown, and lists the bugs and dead code found along the way. No new words: every label is existing app copy. Names like “Sam” are example data.
