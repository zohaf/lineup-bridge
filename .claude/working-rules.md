# Working rules for Claude

How to work on LineupBridge UI tasks. Design rules (no new words, tokens only, components) are in
[design-system-rules.md](design-system-rules.md); token values in [tokens.md](tokens.md); page
layouts in [layouts.md](layouts.md).

- Work only on the UI that was asked for.
- Make the smallest necessary changes to achieve the design.
- Do not run tests, builds, linting, or other verification commands.
- Do not refactor unrelated code or add dependencies.
- Avoid repeatedly exploring or rereading files you've already inspected.
- Reuse existing components, styles, and patterns where practical.
- Do not add features or make extra improvements beyond the requested UI.
- Keep your explanations brief. When finished, summarize the files changed and any remaining work in a few bullets.
