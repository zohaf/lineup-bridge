Proposed changes: four options

The organizer's view of a DJ counteroffer. Each option uses only existing text: the banner "The artist has proposed changes to your offer as highlighted in red" and the "Proposed: {value}" label. Fee and set start time changed; values are examples.

A · Underlined note (as built)

Red note with a 2px red line, above the cards. Old value struck through, "Proposed" in red under it. Clear, but the line reads like a divider and the note is far from the changes.
