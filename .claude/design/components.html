1

Event details

  • White card, 1px border, 8px radius, padding 24px (phone) / 32px (768+).
  • Title row: number in a 28px circle with a 1px black outline and black text, no fill, .h3 title, 1px rule underneath, 16px below the title.

  • Rows sit inside one SectionCard per group (approved Oct 14: one card per group, not one card per item). 1px rule between rows, 16px (phone) / 24px (768+) above and below (--lb-row-pad).
  • Action row: title (.fieldLabel size, 600) → 8px → text (.body, secondary) → button. Phone: button full width under the text. From 768px: text left, button right (auto, min 200px), vertically centred.
  • Link row: the whole row opens a page (role="link", Enter/Space). The price is always at the right end (600, tabular numbers, right-aligned, so amounts line up down the list), the status chip just before it. Phone: title · price on the first line, date · chip on the second. From 768px: title over date on the left, then chip, then price. An optional action (for example Pay) is its own line under the row: full width on phones, right-aligned from 768px (approved Oct 14).
  • Link row hover (pointer only, @media (hover: hover)): the title underlines (offset 3px). No card lift, no shadow.
  • Row buttons are always secondary: a page can show several rows with an action, and only one primary button is allowed per view.
