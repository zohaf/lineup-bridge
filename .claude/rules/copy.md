# UI text

- No new words. Use text that exists in the app. A new key, label or sentence needs Zoha's approval.
- Live wording is the Console `translations.json` hosted asset, which overrides `en.json`. Check a key
  there before quoting it.
- A new key goes into `en.json`, `de.json`, `es.json` and `fr.json`, and is listed for Zoha to add in
  Console.
- Sentence case. No "!". No full stop on a one-sentence caption.
- Terms: "public profile" (never "listing" in UI), "offer", "counteroffer", "final offer".
